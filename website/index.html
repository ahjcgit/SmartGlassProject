01 / Experimental setup

One bottle. One toy.
Different viewing conditions.

Real RayNeo camera recordings give us repeatable input for a paired detector comparison. The same saved images are scored against visible-object reference boxes.

A

Capture on the glasses

RayNeo X3 Pro camera frames, stored at 480 × 640 pixels. Each object has near, middle, and far front-facing trials; a middle oblique trial; and a slow head-pan trial. One additional trial contains neither target.

Five conditions × two objects + one empty scene = 11 trials. Still trials run for 5 seconds; pans run for 8 seconds.

B

Compare the same images

NanoDet Plus at 416 input and YOLOX-S at 640 input, replayed with OpenCV CPU and two threads. The recordings also retain the original live NanoDet outputs.

229 timed calls per model, one repeat per frame, with three warmups per model. The CPU model was not recorded.

C

Score against reference boxes

A hit requires the expected class, confidence ≥ 0.35, and intersection-over-union ≥ 0.50. We evaluate the highest-confidence expected-class box, including when it is wrong.

210 visible-object frames + 19 empty-scene frames. Box extent includes caps, mirrors, and wheels; excludes cast shadows.

Annotation provenance

18 original user annotations were preserved. An AI assistant added 192 visible-object boxes and 19 absent labels by inspecting the images before consulting detector output. Those 211 additions have not been independently human-verified; 48 small or clipped-object frames are flagged for review. All accuracy and placement results remain preliminary.

The live and replay NanoDet hit rates match in this dataset. These are three result streams over 11 physical trials, not 33 independent physical trials. Frames within a trial are correlated.

01

The bottle is condition-sensitive.

NanoDet hits 18/18 middle/front frames, but 0/19 near/front frames and 6/19 oblique frames. This pilot does not support a simple “closer is better” claim.

02

The toy exposes a model limitation.

NanoDet misses every motorcycle frame. YOLOX-S hits 19/19 middle/front and 27/30 slow-pan frames, but neither detector hits the far motorcycle trial.

03

No target false positives in the empty trial.

All three streams produce 0/19 false-positive frames for bottle or motorcycle. One empty scene is too small to establish a general false-positive rate.

The latency tradeoff

Recognition has a budget.

The larger model improves detection in these scenes, while its median CPU model call takes about five times longer. Live integration still needs a measured response-time evaluation.

What can we say about annotation placement?

For the sanitizer slow-pan trial, median top-center box-anchor error is 0.248% of the image diagonal (~1.98 px) for live NanoDet and 0.121% (~0.97 px) for replay YOLOX-S. Corresponding hit rates are 23/30 and 27/30.

These errors are conditional on an available expected-class prediction and are measured against the reference boxes. They measure camera-image localization—not text readability, through-lens alignment, temporal tracking, or world anchoring. A low error on detected frames does not compensate for misses.

Implemented & documented

A shared object, different permitted notes.

The November 9 hardware run documented live color capture on RayNeo X3 Pro and Alice → Bob switching: Alice received three permitted notes, Bob two, excluding Alice’s private note. This is functional demo evidence, separate from the 229-frame detection pilot.

QR identifiers remain available for unique object identity. The model-assisted path detects categories; the user selects the registered instance. A bottle detection alone cannot tell two identical bottles apart.

Read the implementation record ↗

Still to establish

From a prototype to a reliable wearable.

  • YOLOX-S in the live glasses pipeline, including actual response time.
  • Repeated trials, more objects, and controlled lighting and geometry.
  • Wearer-tested optical alignment and readability during movement.
  • Robust recovery and object identity beyond a selected demo target.

The current labels follow repeated detections. There is no independent temporal tracker, SLAM, 6DoF tracking, or persistent world anchor. Motorcycle detection results do not establish a completed motorcycle note-sharing demo.

How to read this pilot

One physical instance per category. One trial per condition. Distances and angles are ordinal, not measured centimeters or degrees. Native model input sizes and preprocessing differ. Detection confidence is not accuracy; hit rate is not mAP. Reference labels are partly AI-reviewed and awaiting independent human verification. Model replay is not a live YOLOX-S hardware test.

Built with native Android, FastAPI, SQLite, and OpenCV. Pretrained NanoDet and YOLOX are reused models. Project contributions are device integration, shared annotations, capture/export, and evaluation.
